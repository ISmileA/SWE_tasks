# Примеры

Появляются при первом `python -m ml_tasks demo`, если файлов ещё нет.

- `dog.jpg` — фото из туториала PyTorch Hub, для классификации.
- `miaow_16k.wav` — мяуканье из туториала YAMNet, 16 кГц.
- `dog_clip.mp4` — короткий ролик, собран из `dog.jpg` (медленный наезд), для детекции.

Свои файлы можно передать в команды `audio`, `image` и `video`. Звук нужен в формате wav.
